# Componentry Playbooks — Public Import Pack

This pack is prepared from the two supplied archives. Original Markdown files are preserved verbatim.

## Copy target

Copy the `content/playbooks/` directory into the root of `componentry-lab`.

Also copy `manifest/playbook-source-manifest.json` to:

`content/playbooks/_manifest/playbook-source-manifest.json`

The private vault is intentionally distributed as a separate archive and should not be committed to a public repository without an explicit review.

## Content groups

- `positioning-judging/` — positioning, hooks, judge path, memory, proof moments, launch copy.
- `uiux/` — interface blueprints, typography, color, components, responsive, composition, research, anti-slop, controlled risk.
- `demo-video/` — demo script system.
- `references/visual-directions/` — project-specific visual direction references.
- `hackathon/evidence/` — evidence and submission playbooks.
- `hackathon/gates/` — audit, distinction, naming, angle-mort, and operating gates.
- `hackathon/templates/` — intake, research, product, judging, portfolio, retrospective, and execution templates.
- `hackathon/ux-ui/` — UX, UI polish, demo, video, and visual production.

## Important

The source documents may overlap conceptually. The manifest records their origin and hash. Registry metadata should reference these files rather than duplicating their full text in TypeScript.
