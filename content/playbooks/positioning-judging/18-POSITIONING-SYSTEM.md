# Positioning System

The Judge-Winning UI/UX System is not only about screens.

A project must be simple enough to explain socially, strong enough to survive technical review, and memorable enough to stay in a judge’s head.

## Core Rule

If the project cannot be explained in one strong X post, the UI is not ready.

## Required Positioning Assets Before UI

Before designing the landing page, dashboard, or video, create:

1. One-line promise
2. Problem tension
3. Judge memory sentence
4. X post
5. Telegram post
6. Hero headline
7. Demo moment
8. Proof/evidence moment

## The Judge’s 10-Second Questions

A judge should be able to answer:

- What is it?
- Why does it matter?
- What is private?
- What is proven?
- What happens if it works?
- What happens if it fails?
- Why should I remember it?

## Examples

Every invoice settlement leaks business data.
BatchGuard proves the batch is compliant without revealing the invoices.
Valid proof settles. Tampered proof blocks.

Settle invoices. Reveal nothing.

BatchGuard is the invoice settlement gate that proves compliance without revealing invoices.
