# Social Launch Pack

The UI is not the only judge-facing surface.

X, Telegram, Discord, LinkedIn, Devpost, DoraHacks, README, and the video all shape judge perception.

## Required Social Assets

For each serious hackathon project, create:

1. X post
2. Telegram/Discord post
3. One-line project description
4. Demo video title
5. Hero headline
6. Judge memory sentence
7. Proof moment screenshot caption
8. Limitation sentence
