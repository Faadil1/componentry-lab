# Judge Memory Sentence

A judge memory sentence is the line the judge can repeat after seeing the project.

## Formula

[Project] is the [simple category] that [memorable action/proof].

## Good Examples

BatchGuard is the invoice settlement gate that proves compliance without revealing invoices.

EdgeVoC is the offline feedback analyst that turns private comments into local insights.

TrustCheck is the agent verification gate that tests before delegation.

CupPulse is the match signal analyst that turns noisy football data into one explainable decision.

ProofPass is the claim audit pass that verifies before trust is granted.

## Bad Examples

An AI-powered platform for enhancing privacy and compliance using modern cryptographic infrastructure.

A dashboard that uses several technologies to improve workflows.

A next-generation solution for secure digital transformation.
