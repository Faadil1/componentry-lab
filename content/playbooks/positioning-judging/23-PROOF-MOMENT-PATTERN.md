# Proof Moment Pattern

Technical proof must become a visible moment.

## Core Pattern

Input
→ Proof/action
→ Verdict
→ Evidence receipt

## Common Proof Moments

- ACCEPTED
- BLOCKED
- CLAIM VERIFIED
- RISK FOUND
- REPORT GENERATED
- LOCAL ANALYSIS COMPLETE
- SETTLEMENT READY
- ACCESS GRANTED
- ACCESS DENIED

## Pass/Fail Pattern

If valid:
[action happens]

If invalid:
[action is blocked]

## Example — BatchGuard

Input:
Invoice batch

Proof/action:
Compliance proof checked

Verdict:
BLOCKED

Evidence:
Receipt shows proof was invalid/tampered/expired/replayed
