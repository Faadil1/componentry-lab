# Hero Copy System

The hero is the compressed version of the project.

## Hero Must Include

1. Project name
2. Sharp headline
3. One-line promise
4. Primary CTA
5. Proof/result preview

## Hero Headline Patterns

### Do X Without Y

Settle invoices without exposing invoice data.

### Prove X Without Revealing Y

Prove eligibility without revealing identity.

### Valid X. Blocked Y.

Valid proof settles. Tampered proof blocks.

### The [category] that [proof/action]

The invoice settlement gate that proves compliance without revealing invoices.

## Hero Anti-Patterns

Avoid:

- “AI-powered platform”
- “next-generation”
- “seamless”
- “revolutionary”
- “secure and scalable” without proof
- technical stack before value
