# Positioning Prompts

## Prompt — Problem Tension

Create a sharp problem tension for this hackathon project.

Project:
- name:
- domain:
- sponsor:
- user:
- sensitive thing:
- proof rule:
- action:
- failure mode:

Return:
1. visible problem sentence
2. do X without Y sentence
3. pass/fail sentence
4. judge memory sentence
5. hero headline
6. X post hook
7. Telegram/Discord intro

## Prompt — Social Launch Pack

Create a social launch pack for this hackathon project.

Return:
- X post
- Telegram post
- LinkedIn post
- demo video title
- one-line description
- judge memory sentence
- proof screenshot caption
- limitation sentence

Rules:
- no vague AI hype
- name what is private
- name what is proven
- name what happens on success
- name what happens on failure
