# Judge-Winning UI/UX System

A reusable Markdown-based system to improve hackathon presentation: positioning, landing pages, dashboards, demo videos, evidence cards, typography, color, components, responsive rules, social launch, and portfolio packaging.

## Core Rule

Structure first. Judge path second. Proof always. Polish last.

## V1.1 Addition

If the project cannot be explained in one strong X post, the UI is not ready.

The system now covers:

- positioning
- storytelling
- landing page
- dashboard
- demo video
- proof receipts
- social launch
- judge memory
- portfolio packaging
