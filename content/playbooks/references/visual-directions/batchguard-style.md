# Example — BatchGuard Style

## Project Type

Signal + Depth

## Judge Moment

BLOCKED

## Core Flow

Invoice batch
→ verification gate
→ accepted/blocked result
→ evidence receipt

## Visual Direction

Sharp, technical, proof-focused.

## Typography

Hero:
- Nativeera-style, Syne, or Aktiv Grotesk

UI/Evidence:
- Geist
- IBM Plex Sans
- Inter

## Palette

Dark proof UI or blue/yellow high-contrast.

## Evidence

- proof status
- batch ID
- receipt
- run timestamp
- limitation card

## Rule

Make private verification visible through a simple accept/block UI.
