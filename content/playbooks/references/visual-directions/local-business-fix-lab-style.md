# Example — Local Business Fix Lab Style

## Project Type

Edge + Business

## Judge Moment

FIX PRIORITY FOUND

## Core Flow

Local business page/data
→ audit
→ issue found
→ fix recommendation

## Visual Direction

Diagnostic, practical, trustworthy.

## Typography

Hero:
- Groote-style
- Satoshi
- Hanken Grotesk

UI/Evidence:
- Manrope
- Inter
- Figtree

## Palette

Dark gray + vivid yellow for audit lab,
or warm neutral + orange for business-friendly onboarding.

## Evidence

- audit result
- before/after
- recommendation card
- limitation card

## Rule

Make the audit feel useful in one glance.
