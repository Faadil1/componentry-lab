# Typography System

## Rule

Hero font creates memory.
Evidence font creates trust.

## Font Roles

### Hero / Wordmark

Can be expressive.

Use for:

- project name
- video title
- poster
- launch graphic

### UI / Dashboard

Must be readable.

Good choices:

- Inter
- Manrope
- Hanken Grotesk
- Neue Montreal
- Pretendard
- Figtree
- Geist
- IBM Plex Sans
- Satoshi
- Host Grotesk
- Liga Sans

### Evidence / Logs

Use readable sans or mono.

Use mono only for:

- hashes
- IDs
- timestamps
- code
- receipts

## Font Pairing Rule

Maximum two font families:

1. expressive hero font
2. readable UI/evidence font

## Avoid

- decorative fonts in proof cards
- too many font styles
- low contrast text
- tiny metadata
- using Inter/Helvetica everywhere by default when the hero needs identity

## Project Mapping

Technical proof / ZK:
- Nativeera-style hero, Geist/IBM Plex/Inter for UI

Local AI / feedback:
- Satoshi, Manrope, Hanken, Figtree

Sports analytics:
- Epic Pro-style hero, Aktiv Grotesk, condensed impact type

Finance / education:
- Instrument Serif or editorial serif for hero, Manrope/Satoshi for UI

Creative / mascot:
- expressive display type for hero only
