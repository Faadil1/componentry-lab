# Color System

A palette is not a design system.
A palette becomes useful when every color has a job.

## Color Roles

Background:
Main page surface.

Card:
Readable content container.

Primary text:
Main readable text.

Muted text:
Metadata and secondary details.

Primary CTA:
Main action.

Accent:
Sponsor or brand highlight.

Success:
Accepted / verified / safe.

Warning:
Fallback / local / caution.

Risk:
Blocked / failed / rejected.

Border:
Separation without noise.

## State Colors

ACCEPTED / VERIFIED / SAFE
→ green

BLOCKED / FAILED / RISK
→ red

LOCAL_STUB / FALLBACK
→ amber

SIMULATED / PRESEEDED
→ purple or gray

LIVE
→ blue or green

LOCAL_VERIFIED
→ blue or teal

## Rules

- Do not use every palette color equally.
- Use color to clarify state.
- Test contrast.
- Avoid pure white by default when off-white works better.
- Keep evidence surfaces calm and readable.
- Use atmospheric gradients around proof, not behind proof.

## Useful Palette Directions

Technical proof:
- near-black, midnight blue, electric accent

Calm AI/reporting:
- arctic teal, cloud pearl, soft neutrals

Business audit:
- dark gray, vivid yellow, off-white

Finance/editorial:
- indigo, cream, forest green, warm neutrals

Creative/mascot:
- bolder accent palettes, but controlled evidence surfaces
