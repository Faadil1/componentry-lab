# Component Rules

## Buttons

Use clear verbs:

- Watch demo
- Run demo
- View evidence
- Open GitHub
- Generate report

Avoid icon-only critical buttons.

## Cards

Use cards for:

- result
- evidence
- limitations
- steps
- metrics

## Badges

Use badges for:

- LIVE
- LOCAL_VERIFIED
- LOCAL_STUB
- SIMULATED
- PRESEEDED
- BLOCKED
- ACCEPTED

## Radius

Use consistent radius:

- small: 8px
- medium: 12px
- large: 16px
- XL: 24px
- pill: 999px

Rule:

Outer radius = inner radius + padding.

## Shadows

Use subtle shadows only.

Prefer:

- border
- spacing
- soft elevation

Avoid heavy muddy shadows.

## Micro UI

Use micro UI elements only to clarify state:

- running
- pending
- saved
- verified
- offline
- local
- blocked

Do not add random decorative dots/icons.
