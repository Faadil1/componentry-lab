# Responsive Rules

Mobile is not squeezed desktop.

## Breakpoint Behavior

### Mobile

Show:

- promise
- CTA
- result preview
- simplified evidence

### Tablet

Show:

- stacked 3-step flow
- result
- evidence cards

### Laptop

Show:

- full input → action → result layout

### Desktop

Add:

- evidence sidebar
- details panel
- larger screenshots

## Rules

- CTA must stay visible.
- Result must stay readable.
- Evidence cards should stack on mobile.
- Tables should become cards if needed.
- Do not make proof text tiny.
- Do not hide the judge moment behind mobile navigation.
