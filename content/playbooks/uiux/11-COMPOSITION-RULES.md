# Composition Rules

Composition controls judge attention.

## Emphasis

One thing should stand out first.

Use for:

- hero promise
- primary CTA
- verdict
- evidence receipt

## Alignment

Cards, labels, buttons, badges, and evidence fields should align.

Poor alignment makes a working project feel unfinished.

## Balance

The screen should feel stable.

Do not let decoration overpower proof.

## Movement

The eye should follow:

Problem
→ Action
→ Result
→ Evidence
→ Limitation

Motion should guide state changes, not distract.

## Proportion

Size should match importance.

Large:

- verdict
- result
- promise
- key insight

Small:

- metadata
- timestamp
- hash
- raw logs

## Repetition

Repeat component patterns:

- badges
- cards
- buttons
- spacing
- screenshot frames

Repetition creates system.
Repetition must not erase state differences.

## 12-Point Visual Audit

- Balance
- Contrast
- Emphasis
- Movement
- Rhythm
- Hierarchy
- White Space
- Unity
- Variety
- Alignment
- Proportion
- Repetition
