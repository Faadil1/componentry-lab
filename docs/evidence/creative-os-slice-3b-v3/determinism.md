# Determinism & Input-Output Signatures

All Creative Method Runtime execution is strictly local, synchronous, and side-effect-free. To verify that identical inputs always yield identical outputs, the runtime computes deterministic signatures from the inputs and outputs.

---

## Fingerprinting Rules
1. **Input Signatures**: Generated by joining normalized input parameters (category, target sensory experience/descriptor, desired positioning signals, and protected trust requirements).
2. **Output Signatures**: Derived from the selected strategic choices, tension level, layout parameters, and active outputs.

---
