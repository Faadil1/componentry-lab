## Fixture C: Eye-Catching (Premium Home Renovation Service)
* **Descriptor**: eye-catching
* **Subject**: premium home renovation service
* **Context**: renovation service

### 1. Physiological Profile
* **Observable Reaction**: saccadic capture, rapid eye fixation shift, momentary breathing suspension
* **Viewer Behavior**: immediate stop on visual anomaly, pointer tracking toward the anomaly
* **Eye Path**: radial outward; initial capture point followed by rapid surrounding context scan

### 2. Perceptual Principles Derived
* Target: `immediate gaze capture`
* Principle: `Isolated visual anomaly`
* Reasoning: `Introducing an off-grid element breaks expectations and forces instant saccadic capture.`

### 3. Formal Options Considered
1. **Oversized, off-grid architectural detail crop**
   * Support: Forces eye to pause on craftsmanship textures.
   * Fit: High-fit (highlights tangible expertise).
   * Stereotype Risk: `LOW`
2. **Neon-accented animated pointer highlights**
   * Support: Snaps attention via chromatic contrast.
   * Fit: Low-fit (conflicts with high-trust construction service).
   * Stereotype Risk: `HIGH` (cheap, aggressive cliché)

### 4. Selected Design Direction
* **Chosen Expression**: `"Oversized, off-grid architectural detail crop"` (low risk, high fit).
* **Rejected Alternative**: `"Neon-accented animated pointer highlights"`.

## Fixtures: Same Descriptor / Multiple Contexts

### Luxurious Perfume vs. Luxury Financial Dashboard
* **Perfume**: Selects an asymmetric, fluid layout with vast whitespace (55%+) and high-contrast display serif typography (alabaster/linen/gold palette).
* **Dashboard**: Selects a golden ratio grid with isolated KPI cards, modern geometric sans-serif typography, and deep obsidian backdrops with precise emerald indicators (no perfume style clichés).
