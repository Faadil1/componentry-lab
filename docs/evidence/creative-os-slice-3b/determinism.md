# Determinism & Input-Output Fingerprinting

All Creative Method Runtime execution is strictly local, synchronous, and side-effect-free. To verify that identical inputs always yield identical outputs, the runtime computes deterministic hashes/fingerprints from the inputs and outputs.

---

## Fingerprinting Rules
1. **Input Fingerprint**: Generated by joining normalized input parameters (category, target sensory experience/descriptor, desired positioning signals, and protected trust requirements).
2. **Output Fingerprint**: Derived from the selected strategic choices, tension level, layout parameters, and active outputs.

---
