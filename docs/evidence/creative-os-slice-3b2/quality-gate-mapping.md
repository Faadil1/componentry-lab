# Quality Gate Mapping Specification — Slice 3B.2

---

## 1. Physical Situation Storyboarder Gates
* `pss.idea-becomes-physical`: Asserts abstract ideas are physicalized through concrete props and action mappings.
* `pss.one-beat-one-function`: Asserts every node carries a distinct, non-decorative narrative function.
* `pss.transformation-visible`: Verifies final subject/object states differ from initial setups.
* `pss.no-exposition-dependence`: Enforces subtext rules (what must remain unspoken).
* `pss.continuity-protected`: Mandates wardrobe, environment, and prop consistency parameters.
* `pss.project-specific`: Enforces character name and category-appropriate elements.
* `pss.no-coaching-drift`: Prevents character dialogue or actions from sliding into coaching instructions.

---

## 2. Relationship-Preserving Abstraction Gates
* `rpa.relationships-not-contours`: Rejects literal tracing in favor of geometric, relative spatial relationships.
* `rpa.high-information-selection`: Asserts between 3 and 6 relational facts are preserved.
* `rpa.hierarchy-preserved`: Enforces survival of primary mass/scale structures.
* `rpa.identity-survives`: Asserts identity preservation rationale is defined.
* `rpa.communication-survives`: Asserts the visual system supports the project objective.
* `rpa.visual-language-constrained`: Limits supporting mark families to at most 2.
* `rpa.project-specific`: Ground visual grammar in the source parameters.

---

## 3. Cognitive Metaphor Illustrator Gates
* `cmi.one-image-one-cognitive-action`: Restricts composition to a single primary relationship.
* `cmi.physical-not-verbal`: Expresses concepts through mechanical physical forces and systems.
* `cmi.cliche-risk-reviewed`: Identifies and rejects common category clichés (plants, lightbulbs, puzzles).
* `cmi.project-specific`: Integrates concept and audience context.
* `cmi.comprehension-over-decoration`: Prioritizes objective comprehension over cosmetic novelty.
* `cmi.no-source-style-copy`: Avoids imitating trademarked mascots or external IP designs.

---

## 4. Library-First Composition Router Gates
* `lfcr.native-first`: Prioritizes native elements when native primitives suffice.
* `lfcr.registry-grounded`: Restricts recommendations to registered Slice 3A assets.
* `lfcr.lifecycle-honest`: Rejects describing experimental candidates as APPROVED.
* `lfcr.discovery-not-production`: Blocks discovery feeds from satisfying production gaps.
* `lfcr.smallest-justified-dependency`: Asserts rejection of larger dependencies.
* `lfcr.evidence-aware`: Reports UNKNOWN when compatibility evidence is absent.
* `lfcr.no-execution`: Prevents code modification or installation instructions.
