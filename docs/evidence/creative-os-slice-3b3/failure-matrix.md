# Failure Matrix

- **NO_MATCH**: method runtime not called, Director still produces one action
- **INSUFFICIENT AUTHORITY**: INTEGRATION_BLOCKED
- **METHOD PARTIAL**: PARTIAL_ADVISORY preserved in Director evidence
- **METHOD BLOCKED**: no positive evidence
- **QUALITY FAILURE**: no positive evidence
- **SUPERSEDED evidence**: rejected
- **SAME project + continuation**: MATCH
- **CHANGED same project**: STALE
- **DIFFERENT project**: INCOMPATIBLE
